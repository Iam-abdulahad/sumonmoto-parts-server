# SumonMoto Parts - Backend Server

This is the backend server for the **SumonMoto Parts** motorcycle parts e-commerce platform. Built with **Node.js**, **Express**, and **MongoDB**, it handles all core server-side operations including authentication, user roles, and product/order management.

## 🔗 Live Website
[SumonMoto Parts Live](https://sumonmoto-parts.web.app/)

## 🛠 Tech Stack

- Node.js
- Express.js
- MongoDB
- Firebase Admin SDK (Google Auth Verification)
- CORS
- dotenv
- mongoose

## 🔐 Features

- Firebase Google login verification
- Role-based access control (admin/user)
- CRUD operations for users, products, and orders
- Secure protected routes
- RESTful API endpoints
